# 💻 PHP × JavaScript チューリングマシン・シミュレーター

PHP（バックエンド）と JavaScript（フロントエンド）を連携させた、Webブラウザ上で視覚的に動作する**チューリングマシン（Turing Machine）のシミュレーター**です。

初期状態として、計算機科学の古典的な例題である**「二進数に1を加算する（インクリメント）マシン」**が組み込まれており、無限テープの上をヘッドが動きながらデータを書き換えていく様子をアニメーションで観察できます。

## 🚀 特徴

- **グラフィカルなビジュアル表示**: 赤い矢印（▲）で表されたヘッドが、状態に応じてテープ上を左右にリアルタイムで移動します。
- **無限テープの疑似再現**: ヘッドが初期データの外側（左右の端）に飛び出しても、動的に空白セル（`_`）が拡張されるため、理論上の「無限に長いテープ」を視覚的に体験できます。
- **選べる実行モード**: 内部の挙動を1つずつ追える「1ステップ進む」ボタンと、自動で計算完了まで動かす「自動実行（オート）」モードを搭載しています。
- **完全スタンドアロン**: 外部のデータベースや重いフレームワークは一切不要。PHPが動く環境であれば、ファイルを1つ配置するだけで即座に動作します。

## 🛠 動作環境

- **PHP**: 7.4 以上の環境を推奨
- **ブラウザ**: Google Chrome, Microsoft Edge, Safari などのモダンブラウザ（JavaScript必須）

🧠 組み込みアルゴリズムの解説
初期状態でセットされているルールは、二進数の「3」に「1」を足して「4」にするプログラムです。

処理のステップ
右端の検索 (init 状態):
ヘッドはまず右へ進み、入力された二進数 11（十進数の3）の右端にある空白文字（_）を探します。

加算と繰り上がり (add 状態):
空白を見つけたら左へ反転します。

1 を読み込んだら、0 に書き換えてさらに左へ移動します（繰り上がり処理）。

0 または空白（_）を読み込んだら、そこに 1 を書き込んで処理を終了します。

停止 (done 状態):
一致するルールがなくなった時点で、マシンは安全に 停止（Halt） します。最終的にテープは 1 0 0（十進数の4）になります。

⚙️ カスタマイズ（独自のルールを作るには）
PHPコード内の冒頭にある $defaultRules 配列、および JavaScript 内の initialTapeInput を書き換えることで、文字列の反転や他の算術計算など、独自のチューリングマシンを構築できます。

PHP
// ルールの定義構造
$defaultRules = [
    [
        "state" => "現在の状態名",
        "read"  => "読み込んだ文字",
        "write" => "書き換える文字",
        "dir"   => "移動方向 (R:右 / L:左)",
        "next"  => "次の状態名"
    ],
    // ...
];
